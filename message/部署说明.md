# 短信同步助手 · 部署说明

> 仅可将本应用安装于**你本人拥有或已获明确授权**的设备。
> 未经授权监听他人短信属于违法行为（《刑法》第253条之一、《个人信息保护法》）。
> 应用图标、前台通知、运行时权限申请均可见，不具备隐蔽性。

## 二、应用端（Android 10 ~ 14）

### 安装
1. 把 `output\SmsSync-release.apk` 传到手机，安装（需允许「未知来源」）。
2. 首次打开会依次申请：**短信权限**（接收+读取）、**通知权限**（Android 13+）。

### 配置界面功能
| 项目 | 说明 |
|---|---|
| 服务器地址 | 如 `http://wzc.life` |
| 设备名称 | 上传时标注短信来自哪台设备 |
| 监听转发开关 | 「立即启动」后生效 |
| 屏幕关闭保持 CPU 唤醒 | 可选，默认关（更费电，恶劣 ROM 才开） |
| 测试上传 | 入队一条测试记录验证链路 |
| 电池白名单 | 跳过系统电池优化（保活关键） |
| 保活指引 | 各国产 ROM 自启动设置说明 |
| 清空队列 | 清除本地待上传缓存 |

### 后台保活机制（低功耗设计）
- **前台服务** + 常驻低优先级通知（IMPORTANCE_MIN，不响铃不横幅）
- **START_STICKY** 被杀自动重启；被杀后 3 秒闹钟拉起
- **看门狗闹钟**：每 10 分钟 inexact 唤醒检查（不申请精确闹钟权限）
- **从最近任务划掉**：2 秒后自动拉起
- **上传期间短暂持锁**（60 秒超时），空闲期 20 秒低频轮询，几乎不耗电
- 失败指数退避 30s → 5min；网络恢复/新短信到达立即重试
- 上传失败的数据**持久化在本地 JSON 队列**（queue.json，上限 1000 条），断网不丢，联网自动补传

### 数据字段（每条短信）
```json
{"id":"uuid","device_id":"ANDROIDID_机型","device_name":"备用机",
 "sender":"10086","body":"短信全文","ts":短信时间戳ms,"recv":收到时间戳ms}
```

## 三、服务器端（已集成并上线）

### 接口
| 路由 | 方法 | 鉴权 | 说明 |
|---|---|---|---|
| `/__sms/upload` | POST | 无需令牌（直连） | 设备上传，JSON 入库 |
| `/__remote/sms` | GET | 远程会话 | 实时收件箱页面 |
| `/__remote/sms/data` | GET | 远程会话 | 数据轮询 |
| `/__remote/sms/clear` | POST | 远程会话 | 清空收件箱 |

### 安全
- 上传接口免令牌直连，但保留防滥用：单 IP 每分钟 120 条限速（超限 429 + 安全日志）、请求体上限 64KB、字段长度裁剪（正文 4096 字符）
- 存储上限 3000 条，超出自动丢弃最旧
- 查看页面与数据接口仍挂在隐藏门禁之后，未经验证一律 404

### 查看
隐藏界面（主页底部「爱沃」三连击 → 门禁验证）→ **选择界面新增「📨 查看短信」**：
- 4 秒自动刷新，新消息高亮；显示 发送方 / 时间 / 设备标识 / 短信全文
- 支持暂停刷新、清空收件箱

## 四、使用流程

1. 隐藏界面 → 查看短信（确认收件箱页面正常）
2. 手机安装 APK → 填服务器地址（如 `http://wzc.life`）+ 设备名 → 授予短信权限
3. 点「电池白名单」→ 按「保活指引」开启 ROM 自启动（可选但强烈建议）
4. 点「测试上传」→ 网页收件箱 4 秒内出现测试记录即链路通
5. 开启「立即启动」，此后所有新短信实时转发

## 五、重新编译

```
powershell -ExecutionPolicy Bypass -File d:\server\message\build.ps1
```

工具链缺失时：从腾讯镜像下载 build-tools_r34-windows.zip 与 platform-34-ext7_r03.zip，
解压到 `C:\Users\wzc\.cache\android-build\`（保持默认目录名），重跑即可。

## 六、已知限制

- Android 14 对后台启动前台服务有系统级限制：服务存活期间收短信无影响；若服务被杀且看门狗拉起被拦，需靠用户开启「自启动 + 电池白名单」兜底（保活指引已列出各 ROM 路径）
- 需接收方短信（RECEIVE_SMS 广播），暂不监听彩信与发送记录
- HTTP 明文传输（frp 隧道本身加密，应用端 usesCleartextTraffic=true）；如需 HTTPS 可在应用配置填 https 地址
